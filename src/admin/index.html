UDisc Import

Upload a UDisc Event results xlsx export to import scores and player data into a weekly sheet. Preview is write-free. Approval commits the import.

Tag Calculation

Calculate tag assignments for all players in a weekly league. Every player in the selected week's sheet is included. Preview is write-free. Confirm writes out_tag values.

Finalize Round

Propagate out_tag values from the weekly sheet to each matching ClubMembers record's current_tag. Only players with a confirmed, nonblank out_tag and a matching ClubMembers record are updated.

Points Results

Doubles weekly points: 1st=2, 2nd=1.5, 3rd=1, every other participant=0.5. Both partners receive the same value and a solo receives the full value. Points are computed from the committed placement when the UDisc import is committed, and this panel is a read-only view of those committed results. Season totals are summed live from them, so there is nothing to confirm or finalize. Tag data is never touched.

Doubles Provisioning

Create the League (with league_format=doubles), ClubMembers, and Week template tabs in the Doubles spreadsheet, and seed its roster from the Singles league. Safe to run repeatedly; the Singles spreadsheet is never written.

Setup Club Members

Create the ClubMembers tab if it does not exist. This is a one-time setup step; players register themselves during check-in. Safe to run repeatedly; existing members are never changed.
